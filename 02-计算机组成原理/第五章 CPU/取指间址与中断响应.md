## 统一记号
R表示寄存器内容，M[a]表示内存地址a的内容。AD(IR)表示地址字段，OP(IR)表示操作码。以下为简化教材模型，不是通用逐拍硬件规范。

## 取指
```text
MAR ← PC
发读命令并等待就绪
MDR ← M[MAR]
IR ← MDR
PC ← PC+L
依据OP(IR)译码
```

L是一条指令占用的编址单元数；照片写PC+1需满足一条指令一单元的前提。PC自增与访存可以在硬件允许时重叠。

## 一次间址
```text
MAR ← AD(IR)
发读命令并等待就绪
MDR ← M[MAR]
EA ← MDR的地址部分
```

照片将EA回填AD(IR)是可采用的一种教学数据通路；也可用独立EA寄存器或暂存位置，不能说所有实现必须修改IR。

## 中断响应
中断需要保留足够状态，通常包括返回位置和部分处理器状态；通用寄存器可能由处理程序按约定进一步保存。

向低地址增长、按单元编址、SP指向栈顶的示意：
```text
SP ← SP−1
MAR ← SP
MDR ← 返回PC
执行内存写入并确认完成
PC ← 中断处理入口
```

照片只列SP/MAR/MDR及写命令，未把“内存实际完成保存”和PSW等状态全部展开；笔记不能因此把断点当作已无条件写入。写入数据、地址及写信号须满足存储器时序，不能先随意触发写再准备数据。

有的向量机制给的是入口地址，有的给出保存入口地址的向量表位置；须区分向量与查表动作。外部中断与指令内部同步异常也不能一概认为都等当前指令完全结束才处理。
