# 第五章原图与识别说明

返回 [[第五章 CPU]]。

共28张，主要正文、公式和时序图可识别。浅色批注、涂改痕迹以及少量右侧/底部文字较淡或裁切，未把无法确认的小字当成确定结论。按文件名字典序编号，不是手写原页码；图片副本保持未修改原样。

原图01/02涉及微程序分类，原图05/18涉及单总线；同一个控制信号在不同图中可能代表不同路径。整理采用约定明确的描述，不混合不同电路来拼出未经验证的逐拍表。

照片引用的教材页未随文件夹提供，相关例题不作臆造；必要时使用明确标记的补充算例。本文只校对并组织已给出的学习范围，不把未拍到的教材章节自动列为缺项。
