# x86算术逻辑与乘除

## 普通运算（Intel语法）
ADD d,s：d←d+s；SUB d,s：d←d−s；NEG d：取相反数；INC/DEC：加减1。INC/DEC会修改若干状态标志，但不修改CF；MOV通常不改算术标志。

AND/OR/XOR按位运算并写回，NOT逐位取反且不改算术标志。SHL为左移、SHR为逻辑右移，SAR才是补码算术右移。移位计数常见为立即数或CL，不能把任意寄存器都当合法计数源。

## 32位无符号乘法
```asm
mul ebx        ; EDX:EAX ← EAX × EBX
```
MUL只有一个显式源操作数，另一个隐含在EAX，完整乘积在EDX:EAX。原图18的`mul d,s`不是合法的普通x86 Intel形式。

## 有符号乘法
```asm
imul ebx       ; 完整有符号乘积到EDX:EAX
imul eax,ebx   ; 截断结果到EAX
imul eax,ebx,5 ; EAX ← EBX×5的低32位
```
IMUL有一/二/三操作数不同形式，不能用一条“结果都存d”的口诀概括。

## 除法
```asm
; EDX:EAX已准备好64位无符号被除数
; 若被除数是EAX中32位无符号数，先xor edx,edx
 div ebx       ; 商EAX、余数EDX
```
```asm
; EAX中存32位有符号被除数
cdq            ; 将EAX符号扩展至EDX:EAX
idiv ebx       ; 有符号商EAX、余数EDX
```

DIV/IDIV均仅一个显式除数。IDIV向0截断，非零余数与被除数同号。除数为0或商超出目标宽度会触发除法错误，不是返回一个截断商就结束。
