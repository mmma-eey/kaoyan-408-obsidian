# 循环与LOOP指令

## 条件跳转实现循环
原图求1到100之和的思路正确。以下为统一整理的32位Intel语法，EAX存和、EDX存i：
```asm
xor eax,eax
mov edx,1
LTEST:
cmp edx,100
jg LDONE
add eax,edx
inc edx
jmp LTEST
LDONE:
```
结果EAX=5050，循环体执行100次。FOR通常分为初始化、条件判断、循环体、更新控制变量，不要求必须用LOOP。

## LOOP
在本章32位地址大小模型中，LOOP先令ECX减1，若不为0则跳转。LOOP本身不改变标志位。

```asm
mov ecx,500
LTOP:
; 循环体
loop LTOP
```
若循环体不修改ECX，执行500次。更一般地，计数寄存器由地址大小决定，不能说所有x86模式下永远使用ECX。

原图03把LOOP“等价”为DEC/CMP/JNE，只能理解为控制流效果近似；DEC和CMP会改标志，而LOOP不改，不能当作完全等价替换。

LOOPZ/LOOPE：减计数后非0且已有ZF=1才跳；LOOPNZ/LOOPNE：计数非0且已有ZF=0才跳。这里ZF来自前面的运算或比较，不是LOOP内部把计数与0比较生成。

初始计数为0时，先减1会回绕，不能直接当作执行零次；若需要零次循环，必须在入循环前检查。
