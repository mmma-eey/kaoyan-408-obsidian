## 使用

下载或克隆整个仓库，在Obsidian中选择“打开文件夹作为仓库”，打开仓库根目录，从“首页.md”进入各科索引。图片保存在“99-附件”，请一并保留。

笔记使用Obsidian双向链接；Mermaid图可在阅读视图显示。GitHub网页对部分Obsidian链接和图片嵌入的显示与Obsidian不同。

正文区分原笔记、修正与补充示例。课程简化模型与实际系统可能不同，做题以题干条件为准。本仓库随学习进度更新，未标为整科全部完成。
